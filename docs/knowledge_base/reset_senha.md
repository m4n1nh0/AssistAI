# Reset de senha

Para solicitar reset de senha, use o portal de suporte interno e escolha a opção "Acesso e Senha".

Informe seu usuário corporativo, sistema afetado e um telefone de contato.

O suporte nunca solicita a senha atual do usuário. Caso alguém peça a senha, o usuário deve interromper o contato e acionar o suporte humano.
