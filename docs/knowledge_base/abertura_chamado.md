# Procedimento de abertura de chamado

Para abrir um chamado de suporte interno, acesse o portal oficial de suporte, informe a categoria do problema, descreva o impacto e anexe evidências quando houver.

O usuário deve informar o sistema afetado, o horário aproximado da ocorrência e uma descrição objetiva do erro.

Chamados críticos devem ser classificados como alta prioridade apenas quando impedirem a operação principal da área.
